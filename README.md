# Student Performance Analysis System

## Overview
A Python application that analyzes student marks, calculates percentages, identifies toppers, and generates performance reports.

## Features
- Reads student records from CSV files.
- Calculates total marks and percentages.
- Classifies students as pass or fail.
- Identifies the highest-scoring student.
- Finds students scoring at least 80%.
- Exports results to a CSV report.
- Handles missing files and invalid data.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- CSV file handling
- Exception handling

## How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run `python main.py`.

## Project Files
- `main.py` — Runs the application.
- `student_analyzer.py` — Contains the analysis logic.
- `students.csv` — Input student data.
- `report.csv` — Generated results.
